## Citation Conventions

### In-Node Reference Format

In every node's `Cross-References` section, use the canonical **Short Name**
from this bibliography followed by section numbers where relevant:

```
- Jackson §7.3-7.4, Griffiths §9.3, Born & Wolf §1.5
- Boyd §7, Siegman §9-10, Agrawal §2-5
- Stix §1-2, Ginzburg §3-5, Chen §4
```

### Canonical Format Rules

1. **Always use the Short Name exactly as listed above.** Never use variants
   (e.g., not "Born&Wolf" but "Born & Wolf"; not "Jackson 3rd" but "Jackson").
2. **Section references use §** (Unicode SECTION SIGN, U+00A7), not "Ch." or "Sec."
3. **No publisher/year after the name** — that's what this bibliography is for.
4. **Landau references**: use "Landau Vol.N" or "LLN" for brevity in
   cross-references (both are acceptable; prefer "Landau Vol.2" in formal text).
5. **Multi-author names**: use "&" not "and" — Born & Wolf, Yariv & Yeh, etc.
6. **Russian names**: use English transliteration (Ginzburg, not Гинзбург;
   Landau, not Ландау).

### First-Mention Rule

In the `Derivation Sketch` or `Core Picture` section (first significant mention
of a source), you may include a full citation once. All subsequent mentions
use Short Name + § only.

### Cross-Skill References

When citing a reasoning node from another skill, use the fully-qualified form:
```
electrodynamics: reasoning.em.nonlinear_optical_response
plasma: reasoning.plasma.laser_plasma_interaction
optics: reasoning.optics.pulse_propagation_nlse
landau-graph: reasoning.adiabatic_invariance

```
